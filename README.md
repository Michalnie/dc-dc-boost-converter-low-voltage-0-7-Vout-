
# dc-dc-boost-converter-low-voltage-0-7-Vout-
TPS6122DCKR based boost dc-dc converter for use with voltages below 6v, the lower cuttof of tps is 0,7V and input can go as high as set output voltage. Using two resistors present on board output voltage can be set.
